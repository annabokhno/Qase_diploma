  **ER:** Открывается страница выбранного проекта.

  **ER:** Тест-кейс успешно создается.

- [x] **Создание Test Run**

# 🔗 API-тесты

- [x] **Авторизация с корректным API Token**  
  **ER:** Пользователь успешно авторизуется.

- [x] **Авторизация без API Token**  
  **ER:** API возвращает ошибку авторизации.

- [x] **Создание нового проекта**  
  **ER:** Новый проект успешно создается.

- [x] **Получение списка проектов**  
  **ER:** Возвращается список всех проектов.

- [x] **Получение информации о проекте по ID**  
  **ER:** Возвращается информация о выбранном проекте.

- [ ] **Редактирование проекта** *(не реализовано)*  
  **ER:** Данные проекта успешно изменяются.  
  **Примечание:** Не удалось реализовать, поскольку метод `PATCH /project/{code}` не поддерживает редактирование проекта.

- [x] **Удаление проекта**  
  **ER:** Проект успешно удаляется.

- [x] **Создание нового тест-кейса**  
  **ER:** Новый тест-кейс успешно создается.

- [x] **Получение информации о тест-кейсе**  
  **ER:** Возвращается информация о выбранном тест-кейсе.

- [x] **Добавление результата выполнения теста**  
  **ER:** Результат выполнения успешно добавляется.

- [x] **Негативные сценарии**  
  **Проверки:**
    - создание проекта без обязательных полей;
    - создание тест-кейса без обязательных полей;
    - запрос с несуществующим ID.

  **ER:** API возвращает соответствующий код ошибки и сообщение об ошибке.
